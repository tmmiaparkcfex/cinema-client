# iPhone 0.3.0+4

以现有影院客户端为基础，首版只支持 `vod-web` 原生接口，保留 Flutter 与 media_kit/libmpv 播放内核。

## 影视资料

- 读取接口已有的 TMDB 身份与 `metadata.version=2`，展示片名、原名、年份、类型、时长、评分、海报、背景图和演职员。
- 按季号和集号关联逐集标题、简介、剧照、播出日期与时长。切换季时按对应目录编号补取资料。
- 本地缓存保留已取得的资料。缺失图片显示占位，缺失资料保持为空，不在手机按片名重新猜测已确认的作品身份。

## Cookie 与快传

在“我的”中连接夸克账号，可直接配置完整 Cookie，也可使用网页登录。Cookie 存入 iPhone 安全存储，仅用于观看者自己的夸克请求。

流程与 vod-web 的安卓适配器一致：定位精确文件、临时转存、向自己快传、取得下载令牌、原画播放。优先读取接口提供的父目录编号，减少全分享扫描；刷新播放地址时重新走快传令牌流程，不自动回退普通下载。

快传失败、取消和退出时只处理已登记的新副本，不清空回收站或批量删除原文件。异步删除任务确认成功后才移除登记，失败保留记录用于重试。快传聊天消息尚未自动删除，可能留有历史记录。账号权限、剩余空间、网络与平台限制仍会影响可用性，不能把快传等同于恒定速度保证。

## 播放器

- 原生视频输出、拖动、双击前后跳转、长按二倍速、选集、换线、自动下一集与本地续播。
- 音轨、内嵌字幕和外挂字幕选择；文字字幕大小与时间偏移调整。
- 屏幕锁定/解锁，原画线路与文件参数面板。
- 本版未增加 AirPlay、画中画或服务器转码功能。

## 安装

1. 使用自己的签名工具签名未签名 IPA，再安装到 iPhone。
2. “我的 → 影视接口”填写手机可以访问的 vod-web 根地址。现有默认值为 `http://172.16.3.70:8790`，可在应用内修改。
3. “连接夸克账号 → 配置 Cookie”粘贴自己的完整 Cookie，验证并保存。
4. 选片播放，检查起播、拖动、暂停续播、换集、退出清理和再次打开同一影片。

## 验证范围

本地已完成真实接口的电影/剧集抽样解析与缓存往返检查。自动化回归覆盖快传请求顺序、两种消息响应格式、令牌缺失、错误会话类型、错误文件、取消、刷新、账号隔离、清理失败恢复与异步删除确认；界面有 iPhone 尺寸的测试渲染。

界面渲染和模拟请求测试不能证明真实账号在 iPhone 上的播放结果。4K 硬解、HDR/杜比视界、音画同步、字幕实效、发热与长时间稳定性需要用实际 iPhone 和片源验收。工程其余历史记录和第三方许可证说明继续保留。
