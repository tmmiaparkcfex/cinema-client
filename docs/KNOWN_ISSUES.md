## 数据与速度

当前 API 为已核验 4K 分享索引；上游仍缺海报及部分资料。客户端支持完整资料字段，缺失时用真实空态，不在手机刮削全库。同一 workId 可以对应多季，聚合依赖搜索能返回其他季；本轮真实多季测试未命中样本，模拟测试通过。

真实 API 单请求本轮抽样 7.6–10.4 秒。缓存和后台补季可减少客户端等待，不能替代服务端提速。

## 播放与清理

- 真实夸克授权、风控、空间不足、转存和 CDN 请求头行为未由真实账号证明。
- 转存占用观看者配额；退出尝试清理，断网/强杀后重启或手动重试。
- 随机会话范围不是真实 UID。显式重新登录后，旧范围残留不由新登录自动删除。
- 转存受理后响应丢失、又未拿到 taskId/fid 时保留未决登记；不能承诺自动清完，也不按同名文件猜删。
- 当前 Windows 二进制为上游 2023 年构建（实测 mpv 0.36 系列）；各端内核升级和维护需单独核查。
- 首帧信号只证明 VideoController 首次渲染；之后复用换源仍需设备验证。
- HDR10/HLG/Dolby Vision、音画同步、硬件解码、发热、功耗和长期稳定性均未验收。
