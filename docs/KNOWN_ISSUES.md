# 支持范围与已知问题

## 已实现（代码层面）

- 首页真实接口数据、精选/最新、主视觉、真实空海报回退；
- 电影/电视剧筛选、分页目录、片名搜索；
- 详情、季集、版本/线路选择；
- 片单、本地观看记录、断点续播；
- 设备内夸克登录（Keychain/Keystore）、分享定位、专用目录转存、取直链、退出清理；
- libmpv 原生播放、HTTP 请求头、Range（依赖 libmpv 实现）；
- 自定义播放控件：播放/暂停、±10 秒、进度条、倍速、选集、音轨/内嵌字幕、画面比例、线路切换、双击/长按快进；
- 自动下一集（8 秒倒计时）、播放结束状态；
- 75 秒准备超时、40 秒缓冲看门狗、取消加载、重新获取地址；
- API 首页缓存、本地错误日志（敏感信息脱敏）；
- iPhone/Android/Windows 响应式导航基础。

## 数据与接口

- 当前只有已核验 4K 分享线路，不是普通清晰度完整片库；
- 首页只取接口前 20 + 20，更多依赖分类页；没有无限滚动首页；
- 海报/简介/演员大量为空，界面如实显示缺失；
- 接口响应较慢：本机实测 3.5–8 秒，移动网络未知；
- 接口没有正式客户端身份、限流或版本号，未来变更可能影响客户端；
- 首页缓存只为本机目录服务，不是服务端缓存。

## 播放与资源

- 夸克第三方分享需要转存后才能取直链；这是平台限制，不是客户端绕行；
- 转存会占用观看者自己的网盘配额；70 GB 级文件尤其明显；
- 退出后会清理，但崩溃/断网后只能下次启动或手动重试；
- 直接播放成功依赖 CDN 对 Cookie/Referer/User-Agent/Range 的要求，未真机证明；
- 直链短时有效；失效后需重新获取；
- 没有服务端代播、转码或 DRM。

## 隐私与安全

- 为局域网测试放宽了 iOS ATS 和 Android cleartext；
- 应用内的 HTTP API 会明文传输目录请求；
- 日志已脱敏，但设备上的应用数据仍属于观看者本机数据；
- iOS Keychain 可能在卸载后保留安全存储项，取决于系统行为；
- 签名凭据完全在用户本地，不在仓库。

## 验证边界

`flutter analyze`、单元/组件测试和真实接口只读测试已通过。它们不能证明：

- iOS 编译成功；
- 播放器可用；
- 真实夸克账号链路可用；
- 4K/HDR/功耗/稳定性；
- 任何 Android/Windows/TV 产物可用。

详见 `docs/VERIFICATION.md` 和 `docs/BLOCKERS.md`。
