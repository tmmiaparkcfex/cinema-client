# 影院 · 0.4.0

iPhone 优先的 4K 影视客户端。在 0.3.1 的设备内夸克转存流程上继续开发，播放使用 **media_kit / 原生 libmpv / FFmpeg**。WebView 只用于夸克登录，不承载视频播放。

本轮仅开发用户 App，不包含运营后台、会员或支付。

## 使用流程

1. 在“我的影院 → 影视接口”填写手机能访问的 API 根地址。默认 `http://172.16.3.70:8790`，已有手动设置会保留。不要在手机填写电脑的 `127.0.0.1`。
2. 浏览首页，或从搜索页进入电影 / 电视剧片库；可按已加载作品的真实年份、类型筛选。
3. 在“我的影院”连接自己的夸克账号。会话保存在设备安全存储，不上传到爬虫服务。
4. 进入详情播放、收藏，或选择剧集 / 文件下载。收藏和观看进度保存在本机。
5. 下载需保持应用在前台。进入播放或切到后台会暂停，之后可手动继续；完成后可离线原画播放。

## 本轮变化

- 首页和详情根据海报提取低饱和背景色；浅色胶囊导航、原画播放按钮、分季及每五集分组的剧照卡片。
- 手动滑动精选海报，真实片库 / 搜索 / 最近搜索、收藏、续播、观看记录和下载入口。
- 隐藏播放器控制栏时，进度事件不再重建整页；显示控制栏时最多每秒更新两次。
- 保留原始 4K 文件及码率，手机显示纹理按实际屏幕像素匹配，避免无必要的 4K 输出纹理。
- Range 请求保留严格字节校验，限制预取并发并在暂停时停止继续预取。
- 播放信息读取实际硬解状态、视频掉帧和 iOS 系统热状态；不会把“请求硬件加速”当成“正在硬解”。
- 下载支持队列、暂停、断点续传、恢复和删除，只操作本应用拥有的文件；下载临时租约结束后释放。

## 编译与签名

GitHub Actions 的 **Build unsigned iOS IPA** 执行锁定依赖、静态分析、测试、界面渲染、iOS Cookie 插件测试和 Release 编译。开发分支推送后自动运行。

下载 `cinema-client-ios-unsigned` 产物中的 `CinemaClient-unsigned.ipa`，在自己的电脑上用个人 Apple ID 签名安装。不要把 Apple ID 密码或夸克 Cookie 加到 GitHub Secrets 或仓库中。个人团队的签名期限以 Apple 当前规则为准。

## 验证范围

目标设备为 iPhone 13 Pro / iOS 18.7.7。自动测试、Windows 或模拟器不能证明该设备上的实际发热、硬解或所有 4K / HDR / Dolby Vision 文件都能正常播放。原先“画面停顿但声音继续”的原因尚未由真机数据确认；本轮修改减少已确认的 UI / 渲染开销，并补充实际解码诊断。请用相同影片和相同时间段比较。

播放器支持内嵌音轨、字幕、外挂字幕、倍速、比例、拖动续播及实际线路 / 剧集切换。弹幕服务、远程字幕搜索、AirPlay / PiP、云端同步不在本次实现范围，界面不提供无效入口。

本轮具体记录见 [0.4.0 开发记录](docs/RELEASE-0.4.0.md)。已有历史验证记录只代表对应版本。

## 本地验证

使用 Flutter 3.47.8 / Dart 3.13.7，依赖版本见 `pubspec.lock`。

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter test test/live_api_test.dart --dart-define=LIVE_VOD_API=http://127.0.0.1:8790
```

真实接口测试只读取目录和资源描述，不读取爬虫 Cookie，不启动转存或播放。
