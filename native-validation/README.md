# 原生播放独立验证

这是影院 App 的独立播放验证工程，使用 Swiftfin 主分支锁定的 MPVUI 0.7.0（`23ba5a72375d7472a15898418a49de2c2e9d0d9a`）。不修改影院的页面、接口和已暂停的手势补丁。

设备目标为 iOS 18.6 及以上。GitHub 使用 `xcode-27`，生成未签名 IPA 并运行原生播放测试。测试包需自行签名安装，Bundle ID 独立，可与影院并存。

内置两段自行生成的 12 秒 3840×1632 / 25fps HEVC MKV，分别为 8-bit + EAC3、10-bit + AAC。它们是格式及操作样片，不能证明真实网络稳定性、长时间功耗或影视资源兼容性。

导入完整的同一影片来比较当前影院和候选播放模块。保持屏幕亮度、网络、充电状态、音频输出和低电量模式一致。测试包可输入直接媒体 URL；不接收影片详情页或夸克分享链接，不包含夸克账号鉴权。

记录按钮导出单次解码、掉帧、缓存、音画时差和系统热状态。未知字段保留未知。系统热状态不是机身温度，模拟器测试不是 iPhone 13 Pro 实测。

MPVUI 的 Swift 封装为 MIT，默认 libmpv 原生构建启用 GPL。本工程用于内部播放验证，不是正式 App 的商业发行方案。上游源码、原生补丁与构建输入位于 https://github.com/LePips/MPVUI/tree/23ba5a72375d7472a15898418a49de2c2e9d0d9a 。发布正式产品前须按最终链接产物落实适用许可证。
